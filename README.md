# Kimchi Drop website

Static, responsive website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file and the assets folder from this package.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then click Save.
6. GitHub will show the website address after deployment finishes.

Do not rename or move files inside assets unless the matching paths in index.html and script.js are updated.
